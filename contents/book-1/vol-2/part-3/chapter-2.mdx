Treating books and documentation like source code unlocks version history, peer review, and reproducible multi-format publishing.

### Directory-Driven Publishing Architecture

When chapters live as plain MDX files organized cleanly by book, volume, and part:

```text
contents/
  book-1/
    vol-1/
      part-1/
        chapter-1.mdx
    vol-2/
      part-3/
        chapter-1.mdx
```

Writers focus strictly on prose and code examples while the publishing engine handles routing, typography, and thematic indexing automatically.
